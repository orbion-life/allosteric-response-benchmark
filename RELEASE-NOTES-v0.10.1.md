# Correcting receiver rankings and preserving reproducible response evidence

This release fixes an indexing error in the temporal analysis. The receiver metadata stores integer residue indices; the old analyzer treated it as a Boolean mask. The corrected calculation preserves the complete top-five order in 175 of 176 informative fresh queries across KRAS, ABL, MYC/MAX and MYH7. One ABL query changes its fifth residue from 361 to 385. All 288 fresh full-matrix error checks remain within 0.002.

The source now validates masks and index lists separately. Six regression tests include adversarial examples and saved receiver-score fixtures for all four proteins. A separately implemented verifier checks all 2,216 query records from the saved generators and kernel arrays. The preceding selection study's 1,916 candidate rankings are also retained after a separate scope check. The correction changes analysis, not the fitted models or raw data.

The updated scientific report explains the corrected results and the next bounded tests of centroid relaxation, coherent loading and independent-family prediction. The editable archive rebuilds all nine pages with identical text and rendered pixels in the recorded environment. These protocols are proposed experiments; they do not establish nonlinear recovery, biological superiority or a quantum speedup.
