# Source provenance and redistribution boundaries

`source/SOURCE-MANIFEST.json` records exact executed input hashes, sizes and public inclusion status. `PUBLIC-MANIFEST.json` records every file in the release packet. The original local transfer receipt is retained outside the public packet for the parent audit.

The own Python code and documentation carry the existing Orbion MIT notice in `LICENSE`. Third-party material retains its own terms; the MIT notice does not relicense it.

- **Faure et al., Nature (2022):** [primary article](https://www.nature.com/articles/s41586-022-04586-4); [Supplementary Table 7 download](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-022-04586-4/MediaObjects/41586_2022_4586_MOESM10_ESM.xlsx). SHA-256: `58abcbd1a08ad9fed8778e3b3e8672bbca84ac5a576f1b0530ddd9f5164fbce2`. The primary article identifies copyright under an exclusive Springer Nature licence; separate unrestricted redistribution rights for this workbook were not established. Missing blanket permission is distinct from deciding whether a particular research use is allowed. Acquire the source directly under its applicable terms. This packet excludes the full workbook, copied author CSV and mutation-level rows; it includes our computed site aggregates, metrics, source hash and replay instructions.
- **Structures:** [1GFC](https://www.rcsb.org/structure/1GFC), [1GFD](https://www.rcsb.org/structure/1GFD), [2VWF](https://www.rcsb.org/structure/2VWF), downloaded from `https://files.rcsb.org/download/ENTRY.cif` and, where used, `.pdb`. PDB archive data are available under CC0 as described by [RCSB usage policies](https://www.rcsb.org/pages/policies). These deposited coordinates are included with accession identifiers and hashes. Any ancillary wwPDB quality values are attributed to the validation source URLs in the included receipt.
- **Ohm:** [upstream repository](https://bitbucket.org/dokhlab/ohm), commit `462a3b1318e24ebe2061137fe88af719ef89c0ae`. The exact archive SHA-256 is `395dc1c3e561e21a65a8a2929331b3eb719ae3d66dba64dfe4c879589da140d5`. Its GPL-3.0 notice is included as `source/ohm-GPL-3.0.txt` and in the source archive. The separately recorded patch replaces two GNU private range-adaptor bases with public C++23 equivalents; it does not alter the scoring formulas. This is the pinned upstream implementation, not a claim to exactly reconstruct the original paper's earlier software. No compiled binary is redistributed.
- **Own inherited model code:** exact dependency files are vendored in `vendor/`; their hashes are listed. They originate in the previously published [v0.6.0 evidence release](https://github.com/orbion-life/allosteric-response-benchmark/releases/tag/v0.6.0). The archive is provenance only: replay uses the included files and requires no original workspace or release download.

No supported nonfunctional-pocket labels are supplied. Missing annotation, an inactive compound, a nonsignificant mutation, and residue-level equivalence are different kinds of evidence and must not be substituted for that endpoint.
