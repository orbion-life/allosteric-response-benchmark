# Frozen GRB2 functional evaluation

This is a predeclared retrospective extension using a single GRB2 C-terminal SH3/GAB2 inferred binding-energy assay. Prior qualification inspected assay schemas, uncertainties, author annotations and sequence mappings. No GRB2 Pulsar scores have yet been joined to the outcomes. It is not an independent-family or lifetime-blind study.

1. Use the previously qualified 1GFC chain A first deposited NMR model, cropped to assayed canonical159–214 (56 residues). Retain original coordinates; no relaxation, repair or outcome-dependent structure selection. The deposited construct has GS and terminalR215 outside this crop. Its stereochemical-quality limitations and the GAB2-bound2VWF P212A receiver-reference difference remain explicit.
2. Keep the previously qualified15-residue GAB2 receiver: target residues within5Å heavy-atom distance of the GAB2 peptide in2VWF, transferred by canonical numbering. Candidates are nonreceiver residues at least6Å Cα distance from the nearest receiver in1GFC. No solvent-accessibility or outcome filter is introduced. Every method uses this same candidate set and receiver. Canonical residue number breaks score ties.
3. Use the existing biquadratic Cα contact model: all pair distances<=10Å plus adjacent sequence neighbours, kappa=beta=mobility=1. Keep all positive Cartesian Hessian eigenmodes above1e-8; exactly six rigid null modes are required. Quartic incident-edge energies are averaged by residue degree. Fit a zero-centred full covariance Gaussian with the existing Newton-CG implementation and stationarity tolerance1e-9. Exact OU delayed covariance is evaluated at tau=1/(smallest positive original Hessian eigenvalue). Score each residue by RMS normalized response to the fixed receiver, using the original full-mode harmonic SD of the same quartic observable. No time, contact radius or model parameter is selected using outcomes.
4. Comparators: exact all-mode harmonic OU dynamics with the same quartic observables and normalization; upstream Ohm commit462a3b1318e24ebe2061137fe88af719ef89c0ae with its existing portability patch, heavy-atom contact cutoff3.4Å,10000 propagation rounds, CLI alpha4.5 (upstream internal0.5), cutoff0.05, seeds11/29/47 and their arithmetic mean; Cα contact degree; negative nearest-receiver Cα distance. Ohm uses all nonhydrogen atoms of the same56-residue crop. Repeat seed11 must reproduce its saved result. Report individual seed behavior; never pick the best seed.
5. Source endpoint: Faure Nature2022 Supplementary Table7, GRB2-SH3 single nonwildtype amino-acid substitutions with matching assay wild-type identity, finite binding/folding ΔΔG and finite positive reported uncertainties for both. These uncertainties are Monte Carlo thermodynamic-fit spreads described as standard errors in the workbook, not independent affinity replicates. Use the same valid substitutions for the binding and folding site aggregates. Require at least10 substitutions per site. Report every excluded site and reason; do not lower this threshold after the join.
6. Primary site outcome is the equal-weight arithmetic mean absolute binding ΔΔG across admitted substitutions. It estimates average mutation sensitivity in the observed substitution set; it is not a calibrated pocket effect or calibrated mutation-to-stiffness response. Folding sensitivity is the mean absolute folding ΔΔG across the same substitutions. The primary metric is Spearman correlation between site scores and binding magnitude on the common eligible site mask. Report all five methods and Gaussian-minus-each-control differences.
7. Primary uncertainty:20000 paired residue-bootstrap resamples, RNG seed20260914. A replicate resamples whole sites, preserving all five predictions and the aggregated outcome together. Mutations never become resampling units. Calculate95% percentile intervals and98.75% percentile intervals for the four Gaussian-minus-control differences (Bonferroni nominal familywise95% across four contrasts). Drop and count only replicates where a correlation is undefined because of constant ranks. These are conditional approximate intervals over assayed sites, not guarantees under spatial dependence and not independent-protein uncertainty. Fewer than12 eligible sites makes inference descriptive/inconclusive regardless of a point estimate.
8. A strong within-assay incremental signal requires positive Gaussian correlation, all four simultaneous lower bounds above zero, and at least0.10 point improvement in rho over each baseline. Failure of this conservative reporting gate is not proof of no effect. No cross-family superiority or challenge-selection probability follows from passing it.
9. Prespecified secondary analyses: (a) top-five canonical residues and their mean binding/folding magnitudes for each method, descriptive without binary positive/negative labels; (b) partial-rank association controlling folding, and controlling folding+degree+distance, on the same site mask; (c) inverse-variance-weighted absolute binding/folding aggregation, with the same variants and site mask, as an aggregation sensitivity; (d)1000 draws of binding/folding energies from their reported Normal marginal uncertainties, propagated to site aggregates without resampling mutations, assessing measurement-model sensitivity. Unknown covariance between fits/substitutions is a limitation; these draws are not a rigorous joint confidence interval.
10. Input-state sensitivity is predeclared for all20 deposited1GFD models: run the same Gaussian/harmonic algorithms with each model's own tau, and report response-score/rank variability against1GFC on the primary common mask. Do not select a model, average states into a new primary predictor, or tune after seeing the results. Ohm/degree/distance primary comparisons stay on1GFC. This sensitivity does not restore molecular realism or resolve the poor structure quality. If numerical gates fail, retain failures and report coverage.
11. No neutral-residue equivalence or supported nonfunctional-pocket set is declared: an assay-appropriate biological equivalence margin has not been justified. Unknown annotations, small point estimates, nonsignificance and inactive compounds are not negatives. The official negative-pocket comparison remains unassessable.
12. Save source/input hashes, unchanged inherited algorithms, own raw full matrices/predictions, receipts, derived metrics and an independent audit. Record total wall time and peak memory; use one BLAS thread per worker. Publisher tables stay in a local-only data directory and are excluded from the public-ready packet; publish download instructions and source hashes. No PDF/repository edit, publication, outreach or memory write belongs to this delegated task.
