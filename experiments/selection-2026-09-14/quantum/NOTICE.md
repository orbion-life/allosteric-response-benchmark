# Sources and redistribution scope

The implemented lookup and phase-gradient construction is informed by G. H. Low, V. Kliuchnikov and L. Schaeffer, [*Trading T gates for dirty qubits in state preparation and unitary synthesis*, Quantum 8, 1375 (2024)](https://quantum-journal.org/papers/q-2024-06-17-1375/). The protocols identify the selected implementation and deviations from ideal asymptotic counts. This package links the paper and does not redistribute its full text.

The Clifford+T rotation sequences were produced with [pygridsynth 2.0.0](https://github.com/quantum-programming/pygridsynth), an MIT-licensed implementation informed by Ross–Selinger synthesis. [Qiskit 2.3.1](https://github.com/Qiskit/qiskit) and [Qiskit Aer 0.17.2](https://github.com/Qiskit/qiskit-aer), distributed under Apache 2.0, supply circuit construction, CDKM adder decomposition and numerical simulation. These installed libraries, their binaries and the branch-local runtime are **not** included in the public evidence manifest. Install dependencies under their own licenses using the pinned requirement files.

`vendor/` contains the project's own earlier scientific helpers copied byte-for-byte with source hashes in `inputs/provenance.json`; it does not contain the installed third-party runtime. Inputs and generated circuits/results should carry the parent project's declared code/data license. This note does not grant new rights over unrelated third-party material. Historical experiment-specific paths and hashes are retained as provenance. No cloud account inventory, credentials, copied official challenge PDF or personal memory is part of this branch's curated public file set.
