# Protein response selection experiments

This package contains the 14 September 2026 temporal, GRB2 functional and complete quantum resource experiments. Each branch separates a passing implementation audit from a scientific acceptance decision. Consult the versioned release guide for current results, exact assets and scope.

- `biology` contains the complete curated GRB2 packet and source-only replay instructions. Publisher assay tables must be acquired separately using the recorded primary source and hash.
- `temporal` contains portable source, frozen protocols and compact fixtures. Full kernels are released as versioned assets; waveform arrays can be regenerated from those raw kernels and frozen operators.
- `quantum` contains source and verification fixtures. Large compiled circuits and execution records are released as versioned assets.

The original failure histories and earlier releases remain available. Numerical checks do not establish biological or hardware advantage.
