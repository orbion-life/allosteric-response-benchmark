# Computational evidence figure

The figure combines three distinct completed measurements. It is intended for the public README at its native size, rather than as a small main-paper panel. The PDF, PNG and editable SVG are generated from the exact CSV tables in this folder. The CSV export script also preserves every source receipt and its hash.

**A, harmonic calibration.** Each point is the largest absolute error over all normalized static covariance G₀, delayed covariance K and response C entries and observation times, compared with the analytic unbounded harmonic result. All ten prescribed rows are shown. Lines join spacing refinements only at the same reflecting face A. The A = 7 and A = 8 points nearly overlap at the finest spacing. The tensor-factorized harmonic calculation does not allocate the equivalent full Cartesian grid.

**B, stability isolation.** Native-input and shared-input rows compare the two local environments at final rank 48 for the predeclared elongated κ = 100, 33³ case. The fixed-V row reports the maximum over all pinned basis checkpoints and both environments' tested eigensolver drivers. These are controlled scopes, not three identically sized benchmark workloads. The dashed line is the unchanged 10⁻⁹ portability allowance. The figure does not imply that the larger native/shared bound discrepancy has been repaired.

**C, nonlinear cost.** Both development κ = 1 finite-grid cases are shown, with reflecting faces ±(4,4,17). Preparation includes the native model, exact harmonic normalizer, equilibrium weights, observable construction, both CSR and stencil assembly, and the separately timed array serialization. The Taylor and Chebyshev values each sum all three fixed queries. “Other checks + startup” is the measured outer worker duration minus those named components; it includes the remaining action checks, benchmarks, runtime metadata, imports, receipt handling and shutdown. The complete worker duration includes both propagators and verification. Both methods share H, F, π and G₀, so their agreement independently checks propagation and the resulting delayed covariance and response, not an independent equilibrium reconstruction. The two boxes are finite-model profiles; they do not establish nonlinear domain or grid convergence. Timing is specific to this host.

To rebuild the plot from its portable CSV inputs, run `python plot_evidence.py` in an environment with Matplotlib. The renderer performs no new scientific calculation. To re-export the CSVs from the preparation tree, run `python export_figure_data.py`; that optional exporter expects the sibling physical-study folder. Public readers can use the included CSVs without that folder.

The first render attempt treated a dependency deprecation warning as an exception, and a second environment lacked Matplotlib. Those logs are retained. The successful renderer used the already available plotting environment with its normal warning policy. The numerical diagnostic retained warnings-as-errors throughout; no numerical source or scientific gate was altered for plotting.
