Source and calculation

This viewer contains 166 measured Cα positions. The trace joins consecutive observed residues. It does not draw the 6OIM reference ligand in the 4OBE coordinate frame.

The shortlist is 60, 69, 62, 61 and 65. The response uses two retained harmonic modes, the biquadratic energy and one slow-mode relaxation time. All 492 harmonic modes define the common score normalization.
