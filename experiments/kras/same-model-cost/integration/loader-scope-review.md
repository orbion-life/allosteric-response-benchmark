# Loader scope and cost completeness

The integrated experiment correctly costs the frozen KRAS d2/33² model. Direct inspection of the existing `experiments/kras/quantum/circuit.py` confirms that `walk_gate` loops over every padded row, uses a unitary signed-amplitude-compatible `StatePreparation`, and creates the walk from loading, SWAP, inverse loading and the zero-register reflection. `factorized_controlled_walk` retains both loading operations. The binary SELECT loop repeats the walk `2**bit` times for every coefficient bit. Consequently degree 42 has 63 logical walk invocations and 258,048 row-PREP/inverse invocations for the 2,048-state padding. This is an implemented logical convention; binary SELECT is not a proposed new improvement.

The cost assessment does not omit loading by assigning it zero cost. It reports array enumeration and storage explicitly, compiles all 12 PREPs for each of two readout families, compiles both relevant coefficient preparations, counts every logical walk/loading invocation, and retains three stopped attempts to synthesize actual row preparations. It also includes the original shared structural/Hessian/harmonic-normalizer receipt and distinguishes the loaded-array classical solve from that upstream work. Each readout's sampling plan is joined only to that readout's own compiled preparation receipts.

No numeric correction is required in the preserved results. The following distinctions are necessary whenever the results are shortened for a paper or release:

1. **The complete primary circuit was not compiled or executed.** The 33,556-CX figure is the sum of separately compiled PREP/COEF/inverse modules at degree 42. Native transition loading, SELECT, SWAP/reflection decomposition within the complete circuit, additional workspace, routing, full depth, device execution time, full-circuit noise and measurement overhead remain unmeasured. They are unresolved costs, not zero costs. Whole-circuit optimization could also change the modular subtotal, so it is not a lower bound.
2. **The three row attempts are specific recorded failures of the current generic constructor.** They cover central row 544, corner 0 and first padded row 1089, not all 2,048 rows or every possible loader. A known 8-GiB statevector requirement at 29 abstract qubits exceeds the local simulation cap; it is not a fundamental quantum hardware memory requirement. The compilation RSS stops likewise do not prove that all structured loaders are infeasible.
3. **The 37,190,400-shot variant total is a sufficient retrospective planning estimate.** It uses the exact classical ranking to set a margin and includes the normalized raw-monomial reconstruction factors. It is not an executed shot count, an optimal bound or a biological confidence interval. The operational interval decision takes measured means and known constants only, and stops unresolved when a declared resource limit is crossed.
4. **The 0.001 device allowance is insufficient for the current ranking gap.** No noise result from the four-state fixture has been transferred to the primary model. Preprocessing/synthesis error, device bias and sampling must remain separately bounded before an actual primary-model interval can be certified. The stored bound concerns this fixed finite model and does not repair physical coordinate, grid, domain or biological error.
5. **Structured neighbour-rate evaluation remains a research hypothesis.** It may avoid exhaustive row controls, but reversible arithmetic, finite precision, workspace, valid-grid indexing, signed Gibbs-weighted observable preparation, centring and normalization still require implementation and complete costing. Binary powers are not free fast-forwarded walks.

The portable fast replay passed after integration. All 86 selected source files still match the explicit source manifest; every replay array matched exactly on this host. The cheaper raw-monomial readout independently reconstructs the frozen response within 2.06 × 10⁻¹⁸. The original version-0.2.0 paths were not written by this integration. No transition compilation was retried and nothing was committed or published.
