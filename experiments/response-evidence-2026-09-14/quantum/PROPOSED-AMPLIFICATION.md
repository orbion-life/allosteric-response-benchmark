# Proposed comparison of shallow amplification for eighteen response queries

**Status: proposed and not executed.** This protocol concerns the existing three-site, nine-mode fixture and the 18 response entry/time outputs used by the direct-readout study. It is a local design and compilation study before any hardware request. It neither changes the scientific 0.002 target nor assumes access to a device or a shot allocation.

We will compare direct Hadamard readout at k = 0, a fixed shallow schedule k ∈ {0, 1, 2, 4}, and the original ideal iterative-amplitude-estimation reference. The existing exact reflection adds four helpers to the six-qubit preparation, so an amplified circuit uses **ten qubits**. Those helpers must return to zero. Native gate counts, routing, coherent depth, calibration and physical allocation must be recomputed for the ten-qubit design; the six-qubit Garnet gate counts and US$554 budget do not apply.

The fixed shallow arm does not inherit the full iterative-amplitude-estimation confidence theorem. For each fixed k the ideal success model is sin²((2k+1)θ), which can be ambiguous in θ. We will retain every compatible branch when inverting jointly allocated binomial intervals and report unresolved intervals as failures to reach the target. The ideal adaptive reference may choose larger powers under its original stopping rule; it is a distinct comparator, not evidence that the shallow arm achieves the same precision. Coverage diagnostics and a valid simultaneous confidence construction must precede hardware interpretation.

For each output, let L = ||Bᵢ|| ||Bⱼ|| in the fixed normalized response representation. The recovered response is Cᵢⱼ = (2p−1)L − G₀ᵢⱼ, so a probability error εp contributes 2Lεp. We will allocate model error, static/numerical error, circuit approximation, device bias and sampling error separately. Every protein extension must use its own norms and reduced operator, rather than reusing the triangle's or earlier KRAS model's constants.

The prospective study tolerances are 0.05, 0.02, 0.01, 0.005 and 0.002. They are test points, not promised outcomes. All 18 outputs and every failed tolerance remain in the report. Compare all arms at both matched total shots and matched coherent calls to preparation or its inverse; record native gates, elapsed seconds and monetary cost separately. Hardware noise must be measured on executed circuits, and its effect on amplified likelihoods checked rather than inferred from readout calibration.

Before any QPU execution, select and record the platform, native circuit sizes, fixed shot allocation, monetary ceiling, joint-confidence method and stopping rule from the local compilation and design comparison. No provider submission is included in this code release. A deeper circuit is admitted only when it fits that budget and supplies improved response precision at comparable complete cost.

Classical controls include the same spectral weighted sums and a matrix-free exponential-action method. Charge construction and preparation both cold and with an explicit count of scientifically distinct queries or settings. Identical outputs are cached on both platforms. The full response matrix remains a required scientific output; selected quantum queries are a separate comparison. The study can quantify an estimator tradeoff and identify a possible scaling path, while practical quantum advantage requires a measured comparison against the strongest classical method.
