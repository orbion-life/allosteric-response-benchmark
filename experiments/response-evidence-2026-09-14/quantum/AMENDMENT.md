# Numerical allowance correction

The first compile run returned a maximum response discrepancy of 1.7650673511671044e-7 after Qiskit optimization level3, exceeding the initially implemented1e-8 numerical allowance. The full initial results and source remain in history/initial-arithmetic-allowance. No circuit result was excluded. The declared numerical allowance is raised to1e-6 before final resource accounting, leaving all measured circuit quantities unchanged. This is a numerical precision correction, not a change to the Gaussian reference or physical noise budget. The protocol already requires compilation discrepancy to be counted. All source output is rerun with the corrected allowance. Readout calibration circuits prepare and measure all six addressed physical positions because routing can change the logical readout position; before/after repetitions have separate filenames.
