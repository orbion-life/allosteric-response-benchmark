# Source and data provenance

The implementation is distributed under the repository MIT license, reproduced in `LICENSE`. The eight inherited source files in `source/` retain the exact bytes used for the reference calculation and Gaussian controls; their hashes are checked against the execution receipt. The new control, analysis and verification scripts are distributed under the same repository license. Third-party numerical packages are dependencies and are not bundled in this archive. Their own licenses apply to installed copies.

This experiment uses a synthetic three-site geometry and specified mathematical observables, not patient records, protein structures, experimental assay datasets or copyrighted literature PDFs. The complete model parameters are in `source/vendor/protocol.json`, and the execution choices are in `protocol.json`. The geometry, three contact edges, fixed covariance and reference inputs are included. Generated arrays, numerical results and execution records are included as evidence under the repository license. No license is asserted for external biological datasets used elsewhere in the repository.

The inherited reference solver and Gaussian implementation were copied from the repository's earlier execution studies. `inputs/source-provenance.json` records source labels and original hashes; `protocol-freeze.json` binds the exact original inputs before this study. Older code and evidence are also available in the [v0.6.0 field-switch archive](https://github.com/orbion-life/allosteric-response-benchmark/releases/download/v0.6.0/pulsar-field-switch-2026-09-14-public.zip) and [v0.6.0 execution archive](https://github.com/orbion-life/allosteric-response-benchmark/releases/download/v0.6.0/pulsar-execution-2026-09-13-public.zip). They are historical provenance, not additional dependencies for saved-data replay here.

Only metadata path labels, one provider task identifier and two historical Markdown links were adapted for public distribution. `PUBLIC-PACKAGING.json` specifies each permitted field or link change and records original and public hashes. The protocol, source algorithms, raw scientific arrays and all result tables remain unchanged. The portable independent-audit wrappers only change path resolution, output destinations and metadata-hash validation; original wrappers and their receipts remain under `audits/original/`.
