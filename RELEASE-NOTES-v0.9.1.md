# Literature rationale for mechanical responses and quantum estimation

Version 0.9.1 updates the scientific report and its editable source. It explains how experimentally tested mechanical allostery models motivate the screening approach, and how a proposed direct quantum overlap estimator relates to the calculated response. The code and numerical evidence remain unchanged from v0.9.0.

The revision changes two main-text paragraphs and the reference page. It preserves the model discrepancy, exploratory biological results, compiled circuit measurements and proposed experiments. The report retains six main pages and three appendices.

The [literature note](https://github.com/orbion-life/allosteric-response-benchmark/blob/v0.9.1/docs/evidence-v0.9.1/README.md) explains the supporting sources and their limits.

For computational replay, use the unchanged [v0.9.0 code and raw evidence](https://github.com/orbion-life/allosteric-response-benchmark/releases/tag/v0.9.0).
