# Project Pulsar: locating and recovering from numerical subspace instability

Date: 12 September 2026. Status: independent source and existing-array audit, followed by a proposed bounded diagnostic. No new model, basis campaign or quantum circuit was executed for this note. The original experiment and immutable v0.4.0 release remain unchanged. This proposed protocol is published in the documentation-only v0.4.1 update.

The immediate objective is to identify the first numerically consequential divergence in the construction, rather than to make the existing verifier pass by changing its tolerance. The saved results support accurate finite-model responses, but the strict bound-reproducibility test still fails. The diagnostic below separates model construction, admitted subspaces and evaluation of the bound. It does not repair the unresolved physical-domain and mesh-convergence failures.

## 2. Where the current implementation can diverge

The seed is the left singular subspace of the three-column observable block F. Each subsequent block is H times the latest admitted frontier. The code measures the block's spectral norm, removes its projection on V twice, computes another SVD, and retains singular values exceeding 10⁻¹² times the pre-orthogonalization block norm. It then admits only the leading columns that fit the next checkpoint and uses those columns as the next frontier. Signs of newly admitted columns are fixed by their largest-magnitude element. The seed signs are not fixed. These conventions are directly visible in `block_basis`.

There are four distinct possible causes, none established yet:

1. **The finite matrices differ before reduction.** The input Hessian eigensolver constructs the three-coordinate frame and the slowest-mode grid scale. A rotation of a degenerate internal eigenspace can preserve the Cartesian span but change the orientation of a finite coordinate cube. Sign conventions alone cannot resolve this issue. Compare the actual Hessian, retained eigenvalues and frame, grid order, energy, equilibrium weights, harmonic scales, H and F before discussing the reduced basis. Record whether differences are equivalent to an explicit signed-coordinate permutation; do not silently align a general rotation of the finite grid.
2. **The residual direction changes before the SVD.** Repeated sparse actions and the subtraction of nearly parallel components can amplify small rounding differences. Good orthogonality of the resulting basis does not imply that the same subspace was admitted.
3. **A dependency decision or truncated singular cluster changes the admitted subspace.** Singular vectors in a tight cluster can vary although the cluster's whole subspace is well determined. A prefix that splits that cluster can be unstable. However, the current checkpoints are multiples of three. If every incoming block retains width three, no partial block is cut. The proposed diagnostic must establish that a partial cut or threshold-sensitive rank decision actually occurs before assigning it causal responsibility. LAPACK's error analysis distinguishes individual-vector conditioning from the conditioning of an entire separated singular subspace (Blackford, 1999, [LAPACK Users' Guide](https://netlib.org/lapack/lug/node97.html)).
4. **The same basis produces different downstream bounds.** The code diagonalizes Hᵣ, clips small negative eigenvalues, forms the actual propagated operator, constructs residual Gram matrices, and sums signed terms in two integrated bounds. Each step needs its own checkpoint. The spectrum of Hᵣ is computed with eigenvectors, whereas the residual spectral norm uses eigenvalues only. SciPy documents that these paths can use different LAPACK algorithms. It also defaults to the `evr` driver for a standard symmetric problem ([SciPy 1.14.1 `eigh`](https://docs.scipy.org/doc/scipy-1.14.1/reference/generated/scipy.linalg.eigh.html)).

The code's SVD calls default to `gesdd`. An explicit `gesvd` comparison is a useful diagnostic of the same residual matrix, not a presumption that one driver is correct. Both implement SVD; their algorithmic paths differ ([SciPy 1.14.1 `svd`](https://docs.scipy.org/doc/scipy-1.14.1/reference/generated/scipy.linalg.svd.html)). The pre-orthogonalization `np.linalg.norm(block, ord=2)` is also a singular-value computation, so recording only the subsequent SciPy SVD driver would miss an earlier numerical dependency ([NumPy `norm`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.norm.html)).

## 3. Proposed diagnostic protocol: two existing cases, one worker, 30 minutes

This is a design for a future local diagnostic, not a claim that it has run. Freeze and hash its executable protocol before execution. Its only cases are, in this order, development κ = 1 at 17³ and elongated κ = 100 at 33³, both at extent 4. Retain the third case's historical rejection as an existing-array control; do not launch another physical model to replace it.

All geometry, springs, β, mobility, harmonic frame conventions, three internal coordinates, quartic observables, harmonic normalization, three times, rate formula, reflecting boundary, rank checkpoints, maximum rank and admission thresholds remain unchanged. In particular, keep the 10⁻¹² dependency threshold, rank checkpoints 3/6/12/24/48/96, 0.002 response-bound gate and 10⁻⁹ portable-array allowance. No reference response may select a rank. Do not tune against the largest observed error.

Two already available local environments provide a bounded implementation comparison: the public repository's `.venv/bin/python` currently reports Python 3.12.14, NumPy 2.1.3 and SciPy 1.14.1; system `python3` reports Python 3.9.6, NumPy 2.0.2 and SciPy 1.13.1. Reverify executable and library identities at launch. These are two local environments, not a replacement Linux replay. A later Linux trace is needed to attribute the historical cross-platform discrepancy specifically.

| Ordered stage | Maximum planned allocation | Required output |
|---|---:|---|
| Inventory, protocol hash and small comparison fixtures | 120 s | Source hashes, environment record and comparison self-tests |
| Native construction of both cases in both environments | 180 s | Four H/F input bundles and upstream construction diagnostics |
| Unchanged basis construction on native and shared frozen inputs | 600 s | Complete thin-basis and frontier traces; maximum eight runs, with duplicates reused |
| Evaluation of identical frozen V/H/F under alternate eigensolver drivers | 240 s | Bound decomposition and driver-isolation results |
| Re-evaluation of the first implicated residual block with the second SVD driver | 360 s | Identical-input SVD reconstruction, rank and subspace comparison; at most one forward continuation per case |
| Independent comparison, hashes and failure disposition | 180 s | First-divergence report, all failed comparisons and complete timing |

The schedule allocates 1,680 seconds, leaving 120 seconds inside the hard 1,800-second aggregate cap for monitoring and shutdown. Stage limits are upper bounds, not entitlements to a new attempt. Count all subprocesses, failed attempts, warm-up, diagnostics and serialization against one monotonic clock. Stop at 4,000,000,000 bytes aggregate process RSS, sampled at least every 0.25 seconds, using one numerical worker. Set `OMP_NUM_THREADS`, `OPENBLAS_NUM_THREADS`, `MKL_NUM_THREADS`, `BLIS_NUM_THREADS`, `VECLIB_MAXIMUM_THREADS` and `NUMEXPR_NUM_THREADS` to 1 before importing numerical libraries, and verify active pools where available. Do not launch CI or remote compute as part of this local allocation.

Capture Python, NumPy and SciPy versions; operating system and CPU architecture; executable paths and hashes; compiler and linked BLAS/LAPACK configuration; active thread pools; and `finfo` properties for float64 and longdouble. NumPy's runtime report exposes relevant runtime-library information ([NumPy `show_runtime`](https://numpy.org/doc/stable/reference/generated/numpy.show_runtime.html)). Record actual precision instead of assuming that `longdouble` increases it. Treat warnings as errors and reject nonfinite data. Do not replace a failing arithmetic backend silently.

### 3.1 Freeze the physical finite matrices before investigating the solver

For each native construction, save the original 9 × 9 Hessian; its eigenvalues and complete three-column retained frame; sign-pivot indices and pivot margins; grid shape, coordinate order, axis and spacing; energy; node energies; π; harmonic standard deviations; F; CSR `data`, `indices`, `indptr` and shape for H; and query times. Save invariant checks, minimum/maximum values and hashes of both files and canonical array bytes. Preserve native CSR storage order for the baseline; a sorted copy can support a separate semantic comparison.

Use one designated bundle from the pinned environment as the shared input in both numerical environments. That comparison bypasses native model construction, so any later differences arise after identical finite inputs. Compare native-versus-shared results within each environment separately. Do not overwrite native inputs with aligned or rounded values. An observed native H/F difference is an outcome to explain, even if the response matrix remains close.

Instrumentation must be a new, hashed copy or wrapper that only saves values around the existing operations. Verify that instrumentation reproduces the uninstrumented case under the same environment. Save the unchanged-source hash and the exact instrumentation diff. Do not introduce a new recurrence or driver into this baseline trace.

### 3.2 Save every admission, not only the six checkpoints

For the initial seed and every frontier expansion, record:

- The iteration, incoming rank and frontier width; the incoming frontier and the full existing thin V, or an append-only sequence of admitted blocks from which V is exactly reconstructed.
- The raw block W₀ = H·frontier; the exact scalar `original_scale`; both projection coefficient matrices; W after each of the two subtraction passes; all singular values, thin left and right singular vectors, and the reconstruction residual of the SVD.
- The threshold θ = 10⁻¹² max(original_scale, tiny); every ratio σᵢ/original_scale and signed threshold margin σᵢ − θ; the full keep mask; the number eligible before a checkpoint cut; the number admitted after that cut; every discarded column; sign pivots and margins; and the next frontier.
- Full V orthogonality and seed-containment errors after admission. Record both maximum-entry and spectral/Frobenius measures, with units and normalizers. Store diagnostics separately from the quantities used by the original algorithm.

A rank-96 basis at 33³ states has 3,449,952 float64 entries, about 27.6 MB. Thin bases and three-column residual blocks are practical within this diagnostic. A dense 35,937 × 35,937 projector would require about 10.3 GB before overhead and must never be constructed. Append-only admitted blocks avoid saving many redundant full bases. Stream trace records and load no more than the compared runs plus current thin matrices into memory.

### 3.3 Compare subspaces without mistaking a coordinate gauge for an error

First record unequal ranks explicitly. A principal-angle routine returns only the smaller number of angles; it does not by itself expose an extra direction in the larger space. For equal ranks, use the singular values of QₐᵀQᵦ together with orthogonal-complement residuals to obtain principal angles. Qₐ and Qᵦ are separately orthonormalized *comparison copies*; the original V remains untouched. Save all angles, not only the maximum. SciPy's implementation computes column-space angles and cites Knyazev and Argentati (2002) ([SciPy 1.14.1 `subspace_angles`](https://docs.scipy.org/doc/scipy-1.14.1/reference/generated/scipy.linalg.subspace_angles.html)).

Also compute both directional gaps, ‖Qᵦ − Qₐ(QₐᵀQᵦ)‖₂ and ‖Qₐ − Qᵦ(QᵦᵀQₐ)‖₂, using thin products. Their maximum detects an unmatched dimension and avoids forming a full projector. Do not rely on `arccos` of a singular value extremely close to one to resolve a tiny angle. A cross-check using residual singular values provides better resolution there.

Compare all eligible residual vectors as a whole subspace **before** truncation, then the admitted subspace **after** truncation. Align frontiers by an orthogonal Procrustes rotation only for a diagnostic comparison; never feed the alignment into baseline construction. Compare SVD residuals and singular-value gaps against the measured same-input perturbation scale. A well-conditioned full residual span followed by a divergent admitted prefix would support a truncation explanation. Divergence before the SVD would instead implicate recurrence arithmetic or earlier input differences.

Save every discrepancy and report the first nonidentical byte, first rank/keep-mask difference, and first subspace gap above each of 10⁻¹², 10⁻¹⁰, 10⁻⁸ and 10⁻⁶. These thresholds describe where divergence becomes visible; they do not replace the existing physical or portability gates. Do not retroactively select a single reporting threshold that conceals earlier differences.

### 3.4 Separate basis instability from evaluation of the bound

At each original rank checkpoint, freeze HV, Hᵣ before and after symmetrization, VᵀF, the full eigensystem, clipped eigenvalues, the actual propagated Aused, residual R, RᵀR, the rotated residual Gram matrix, and VᵀR. Save mass-matrix and seed defects, eigenpair reconstruction residuals, and direct singular values of R. Compare the residual singular values with square roots of the nonnegative residual-Gram eigenvalues; this is a diagnostic of loss through Gram formation, not a replacement of the original bound calculation.

For every observable and time, save φ and ψ kernels, the signed quadratic sums I and J, their absolute term masses, the arithmetic allowance, the static correction, the initial-span term, the mass/parallel correction, the one-sided, two-sided and uniform bounds, and which branch supplies each final minimum. Measure the gap between the two competing branches. This distinguishes a change in residual geometry from cancellation, clipping or switching between similar bounds.

Use the same stored H, F and V to compare `eigh` drivers `evr`, `evd` and `ev`. Keep each driver's own actual propagated operator consistent with its own residual. Do not mix a trajectory using clipped eigenvalues with a residual formed from an unclipped operator. Reconstruct the response and test the bound against the same saved full reference only after rank selection. No cancellation test justifies treating a heuristic allowance as a directed-rounding certificate.

At the first implicated residual step, run `gesdd` and `gesvd` on identical saved W. Keep the original SVD result, all singular values and the exact cutoff decision. A bounded continuation from that exact frozen pre-step state can show whether changing this one operation accounts for later divergence. It cannot establish cross-platform recovery or general stability on unseen inputs.

### 3.5 Required comparison self-tests and stopping disposition

Use small, explicitly constructed fixtures before interpreting protein-independent model traces: a sign-flipped basis; a rotated basis with exactly the same span; a basis with one genuinely new orthogonal direction; unequal nested ranks; a repeated-singular-value block whose full span is stable but a selected prefix rotates; a threshold-straddling residual; and a nonfinite input that must be rejected. Require the first two to be classified as gauge-equivalent, the next two as different spaces, and the split-cluster fixture to expose the admitted-prefix change. Perturb a projected matrix while keeping V fixed and require the downstream evaluator to identify this separate stage.

A successful diagnostic identifies the earliest responsible stage with a saved identical-input comparison and quantifies its effect on later subspaces and bounds. If it merely reproduces sensitivity, its status is “divergence reproduced; cause unresolved.” If the resource cap prevents completion, record the last finished stage and the missing checks. Neither outcome is a repaired portability result. Preserve the original source, release hashes, Linux failures, historical timing failures and the development 33³ bound rejection.

## 4. Recovery alternatives to test only after attribution

These are future solver implementations on the same scientific model. They are not approved replacements or demonstrated fixes.

**First preference: avoid an ill-conditioned partial block, if it is actually implicated.** A separated cluster of close singular values can have a stable span even when individual vectors do not. Keep the complete admissible block or complete separated cluster and evaluate at the resulting rank. If doing so would exceed the frozen rank cap, reject at the cap or preregister a different cap in a new experiment. The rank schedule and work differ from v10, so preserve a separate version and rerun all cost and fidelity gates. An empirical cluster rule must be fixed before new cases and justified by observed backward errors and spectral separation, rather than chosen to rescue the known example. Sign fixing cannot stabilize a split degenerate cluster.

**Second preference: a fixed-order, fully reorthogonalized recurrence.** Start from the original observable columns in their canonical order and use an explicitly specified Householder-QR or twice-reorthogonalized modified Gram–Schmidt construction with deterministic column ordering, pivot ties and dependency decisions. Preserve the full frontier rather than discarding an arbitrary suffix. QR with column pivoting is a rank-revealing construction, but near ties still require a declared policy; it does not promise bitwise portability ([SciPy `qr`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.qr.html)). Changing the seed orientation is harmless for a complete exact Krylov space but can affect a truncated floating implementation, so this alternative needs its own baseline and acceptance record.

**Third preference: scale the recurrence, if cancellation or spectral amplification is implicated.** Scaling H by a fixed positive power of two, with inverse time rescaling and correctly transformed residual formulas, leaves the target semigroup unchanged. A bounded Chebyshev recurrence on a declared spectral interval is another possible polynomial basis for the same exact Krylov spaces before truncation. It changes the numerical recurrence, dependency decisions and cost. A spectral interval can be chosen independently using a conservative sparse row-sum bound. Neither scalar scaling nor Chebyshev recurrence guarantees stable admission. Do not silently alter F column scales, whose relative weighting influences truncated selection.

Improved arithmetic or mass-aware projection may be justified by the measured defects, but they are separate implementations. Higher-precision summation does not make every preceding LAPACK operation higher precision. A verified enclosure of the bound requires outward control of matrix construction, projection, spectral approximation and residual integration, not merely an extended-precision final sum. Until such an enclosure exists, retain “calculated finite-model bound.”

A future portable verification policy may test each actual computed reduction's own validity and stable scientific decisions without demanding identical basis coordinates. However, changing that policy requires a mathematical rationale, a preregistered comparison, corruption-rejection tests and new evaluation cases. This note does **not** replace the existing absolute 10⁻⁹ bound comparison with a looser or relative tolerance.

## 5. Separate proposed quantum role after a physical model is accepted

The clearest matched task is to estimate selected signed thermal-propagator overlaps **on the accepted original sparse relaxation operator H**, with the same F, times, normalization and required response precision as the classical methods. The classical reduced operator is then a strong comparator, not an unexamined quantum input. For each pair, the quantity is Fᵢᵀ exp(−tH)Fⱼ, followed by the same equilibrium subtraction. Begin with one specified off-diagonal query and its sign, then a small complete response matrix; freeze the query list before quantum cost calculation.

This choice gives the quantum experiment a precise conditional role: testing whether controlled sparse-walk propagation can answer the same thermal-response queries at a useful complete cost. It does not establish that role will be useful. Classical sparse `expm_multiply` and an accepted observable-preserving reduction must both be evaluated at the same error and confidence requirements, including construction, basis selection, preprocessing and reconstruction. If a rank-48 or rank-96 classical exponential already answers the workload cheaply, that is adverse evidence for a quantum implementation of the same small projected matrix and must remain in the comparison.

The direction-register walk applies only when the accepted discretization has the required nonnegative reversible transition construction and known neighbor rules. A changed physical measure or mobility needs a new rate derivation before using that walk. Hᵣ is symmetric positive semidefinite under its projection assumptions, but can have dense, sign-indefinite off-diagonal entries. It is not automatically a stochastic generator or an instance of the original local direction map. Encoding Hᵣ would require a separately specified general block encoding with loading, coefficient norm, precision and workspace costs; its dimension alone is not a circuit-resource estimate.

The matched original-grid experiment must include equilibrium and signed-observable preparation; transition-rate evaluation; all inverse and controlled operations; coefficient preparation; padding and boundary handling; the complete native gate count, routing and workspace; and physical-response confidence intervals after reconstruction. Retain the failed direction-register canary as history. Its small-model walk algebra is useful implementation evidence, but the operation-cap failure did not produce a complete readout or matched compiled saving. The abstract 21-versus-29 register estimate is not a measured saving and is not a performance gate for this proposed task.

If no accepted physical model and affordable complete quantum circuit meet these conditions, the appropriate proposal milestone is a falsifiable matched-cost test with a stop condition. The numerical recovery work should first establish a stable and physically defensible classical target; it should not manufacture a quantum use case by weakening that comparator.
