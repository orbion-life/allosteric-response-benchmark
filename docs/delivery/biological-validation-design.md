# Project Pulsar: a specified biological comparison and its delivery requirements

Prepared 13 September 2026. This is a proposed analysis design, not a completed external benchmark or a commitment from the named contributors. The analytical precision calculation is complete. This design does not include newly scored protein labels, an additional Ohm run or an implemented general comparator adapter. It is published alongside the separate numerical recovery experiments.

## One primary comparator can be specified now

**Recommendation: use the archived Ohm implementation at commit `462a3b1318e24ebe2061137fe88af719ef89c0ae` as the primary external comparator.** The choice follows input and output compatibility and an existing reproducible local implementation. It is not justified by the favourable KRAS comparison. Wang et al. (2020) introduced static-structure perturbation propagation and residue coupling scores, with retrospective tests on 20 proteins and experimental comparisons for CheY. That evidence supports a relevant comparator, not superiority on the proposed cohort. [Wang et al., 2020](https://doi.org/10.1038/s41467-020-17618-2).

AlloPred uses normal-mode perturbation and pocket features in a trained classifier. Its native prediction unit is a pocket. A five-residue list therefore requires an additional declared conversion and training-overlap review. Keep AlloPred as a secondary pocket-level comparison until that adapter is specified; do not select five favourable residues from a predicted pocket after inspecting labels. [Greener and Sternberg, 2015](https://doi.org/10.1186/s12859-015-0771-1).

The archived Ohm code is a later implementation, not an exact reconstruction of the 2020 article. Direct code inspection shows that it excludes all backbone–backbone contacts by default, symmetrizes its probability matrix using the upper triangle, maps command-line alpha 4.5 to internal alpha 0.5, and always transforms propagation frequencies using path distance. Calling the output a calibrated probability would be incorrect. The existing KRAS receipt records seed-sensitive lists and a bitwise same-host reconstruction of four output files. There is no ABL Ohm artifact in the inspected public ABL directory. Neither the KRAS result nor installation success establishes external accuracy.

### Exact proposed adapter

1. Record the raw input structure, biological assembly, domain, sequence map, coordinate selection, missing atoms and all file hashes. Both methods receive the same permitted coordinate source and receiver. Ohm uses its observed heavy atoms; Pulsar uses the corresponding alpha-carbon nodes. This is equal access to the structure, not an assertion that both models use identical features.
2. Remove reference modulators and every input ligand after using only the separately permitted input ligand to define its receiver. Do not describe a ligand-conditioned coordinate model as experimentally apo. Do not use a reference contact map in input preparation.
3. Export the selected protein chains in a deterministic atom/residue order. The Ohm index file is an explicit bijection to the canonical sequence map. Derive its one-based receiver indices from that file. Canonical residue numbers cannot be passed directly in a different construct: their equality to indices in the old KRAS run was a special case.
4. Use the archived compiler patch and build procedure without a scientific-code change. Run `contacts input.pdb -oi input.ind -oc input.mat -c 3.4`. Run `diffuse aci input.mat RECEIVER_INDICES nodes bonds -n 10000 -c 0.05 -norm -a 4.5 -seed SEED -mdist mdist`. Preserve the command, compiler, archive, patch, input and output hashes. The retained `-norm` flag does not select a branch in this code.
5. For the new external analysis, use the arithmetic mean of the three native node scores from seeds **11, 29 and 47**, each with 10,000 rounds. This is a proposed fixed ensemble to expose and reduce sensitivity to one stochastic draw; a reduction in external ranking error has not been demonstrated. Preserve the three individual rankings. This does not replace the historical single-seed KRAS primary result. No alpha or seed is chosen using external contacts. If a seed fails or emits a non-finite score, mark the primary comparator incomplete; do not average only successful seeds.
6. Apply the identical candidate set to both methods: receiver exclusion and at least 6 Å minimum alpha-carbon distance from a receiver residue. Retain 4/8 Å sensitivities as secondary only. Do not introduce a surface filter without a separate recorded sensitivity. Sort decreasing native score, then canonical chain/residue key; return five unique residues. Store all scores and masks, not only a shortlist.
7. Unit-check index mapping, receiver exclusion, candidate parity, finite scores, exactly five distinct outputs and tie handling using synthetic fixtures. Reconstruct the archived KRAS comparator without changing its historical parameters. Check each installed compiler before the external batch. Different standard libraries can change pseudorandom draws; do not promise cross-platform bitwise identity.

The source archive and patch retain GPL-3.0, separately from original Pulsar code. The executable path is already present in the released KRAS pilot; the generic multi-target adapter and three-seed aggregation described here are **not yet implemented or run**. The adapter should be completed before external labels are released. Harmonic, distance-Hookean and equilibrium responses remain mechanistic controls, rather than substitutes for the primary biological comparator.

## The first biological deliverable is an auditable inventory

ASD2023 is a candidate source universe, not an already eligible cohort. Its experimentally supported protein–modulator entries and associated primary studies can identify candidates; predicted pocketome entries cannot supply experimental positive labels. The original Ohm and AlloPred datasets should be used to identify development overlap. Database size does not establish the number of suitable independent families. [He et al., 2024](https://doi.org/10.1093/nar/gkad915).

Use a separate label custodian only when that responsibility is explicitly assigned. The custodian checks the reference and assay sources, records eligibility and retains the labels separately. The prediction team receives input mappings, receivers, structural quality and eligibility reasons. Public records make this a retrospective benchmark even if label access is operationally restricted. If the same analyst already knows the labels, disclose that fact and do not call the analysis blinded.

Create one inventory row per potential independent family **before running its predictions**, with these mandatory fields:

- Source database/release/accession and primary evidence DOI; input PDB, chain/assembly, sequence accession, coordinate/sequence hashes, domain and mutations.
- A documented family grouping and relatedness evidence, plus links to every development, training or validation set checked for overlap. Conservatively group homologous domains; use a recorded structural classification and sequence-relatedness review rather than assuming different PDB IDs are independent. KRAS, ABL, MYH7 and MYC families are excluded from external confirmation and retain their separate development or specified-target roles.
- An input-derived or independently annotated functional receiver, with supporting source and exact residue map. It must not be selected to maximize coupling to the reference pocket.
- Observed input heavy-atom coverage, alpha-carbon coverage, connected model, construct/assembly comparability and absence of an unresolved receiver ambiguity. Record compatible input and reference states. The allosteric ligand must be identified independently as functional, not merely a crystallographic additive.
- At least five eligible candidates, a compatible native Ohm output, an attainable Pulsar representation under the recorded numerical and resource gates, and an explicit handling plan for missing reference atoms. Reference eligibility may use global coverage assessed by the custodian, but cannot depend on whether either method's top five hits the ligand.
- A contact-label manifest and its hash held separately; a named curator and reviewer, their review status, exact reasons for exclusions and the planned analysis-set assignment.

Use at most one primary input and reference state per family for the first analysis. Additional inputs are within-family sensitivity cases, not additional sample size. If a family has several equally eligible pairs, select by a declared input-quality hierarchy before prediction: resolved receiver, greater required-atom coverage, then better documented structure quality and deterministic accession tie-breaking. The precise quality comparison must respect experimental method; one must not rank crystallography, NMR and cryo-EM by an invented common resolution scale.

Enumerate the complete eligible inventory, select the sample before viewing predictions or labels, and record the sampling rule. A systematic or random selection from that inventory permits a claim about that source population under the design assumptions. A convenience sample permits a narrower claim about the named families. No minimum number of eligible families has been established here; the empty `cohort-template.json` is intentional. `audit_cohort.py` checks the required declarations and source-file hashes, not their biological truth.

### Admission and failure policy

The first milestone must produce the actual inventory count, classifier/receiver/input compatibility report, measured per-case engineering cost, selected precision scenario and accountable owner. The cohort is not locked by writing “12–20 families.” A family that fails before admission remains in the screening log with its reason. An admitted family that later fails remains in the analysis denominator and coverage report; it is not replaced by an easier family. A failed baseline cannot be assigned zero accuracy to make Pulsar look better.

For every completed shortlist, all five positions remain in precision@5. Known non-contact means absence of the declared reference-ligand contact under its recorded atom-coverage rule; it does not mean functional inactivity. Unresolved contact status remains unknown. A method cannot skip unknowns or promote a sixth-ranked residue after reference inspection.

For family f and residue r, define a coefficient a_fr = (1[r in Pulsar top five] − 1[r in Ohm top five])/5. If several predeclared states are included, average these coefficients within the family first. The known-label contribution is d_f0 = sum over known positives of a_fr. The exact paired missing-label bounds are d_f,L = d_f0 + sum over unknowns of min(a_fr,0) and d_f,U = d_f0 + sum over unknowns of max(a_fr,0). An unknown shared by both methods cancels. Both methods must share one label assignment, rather than treating the same residue as positive for one and negative for the other. Missing method outputs make its unobserved predictive accuracy [0,1] for this conservative comparison; count its operational delivery yield as zero separately.

Publish the family identification interval [mean(d_f,L), mean(d_f,U)], every failure and observed coverage. A t interval from unknown-label midpoints is not valid missing-data treatment. The planned t-based comparison applies to fully observed family differences; if the admitted panel contains unknowns or missing outputs, do not drop them to manufacture a complete cohort. Use the predeclared conservative bounded-difference sensitivity below and describe the result as partially identified. A positive confirmatory claim requires the uncertainty-aware result to pass, not merely the complete-case sensitivity.

## Precision follows independent families, not residues

For fully observed independent family differences d_f, estimate the equal-family mean difference and its paired 95% t interval, d-bar ± t_(0.975,n−1) s_d/sqrt(n). This is the paired mean calculation described by NIST; its small-sample interpretation assumes approximately normal independent family differences. Discrete, skewed and heterogeneous P@5 differences can violate that approximation. [NIST/SEMATECH, n.d.](https://itl.nist.gov/div898/handbook/prc/section3/prc312.htm).

The executed `precision_scenarios.py` computes **96 analytic planning scenarios**, not protein observations. It uses n = 12, 20, 30, 40, 60 and 100; assumed paired SD = 0.15, 0.25, 0.40 and 0.60; and assumed gains = 0, 0.05, 0.10 and 0.20. No independent empirical SD has been established. Required sample sizes refer to nominal interval half-width under that SD, not guaranteed realized precision.

| Assumed paired SD | Half-width at n = 20 | Families for half-width ≤0.10 | Families for half-width ≤0.05 |
|---|---:|---:|---:|
| 0.15 | 0.0702 | 12 | 38 |
| 0.25 | 0.1170 | 27 | 99 |
| 0.40 | 0.1872 | 64 | 249 |
| 0.60 | 0.2808 | 141 | 556 |

The proposal's 0.10 practical gain is a design target, not a programme rule or an established biological threshold. Under the normal planning model, a true mean gain of exactly 0.10 has at most a 50% probability of meeting a rule that also requires the observed mean to be at least 0.10; increasing n does not make that boundary target an 80%-power success criterion. The script integrates over sample-variance uncertainty to calculate the joint probability of a positive 95% interval and the point target, separately from the probability of a positive interval alone.

A conservative sensitivity avoids the normal approximation: because each family difference lies in [−1,1], independent-family Hoeffding bounds give h = sqrt(2 log(2/alpha)/n). For unknown-label lower and upper contributions, a union of their two one-sided bounds gives [mean(d_L)−h, mean(d_U)+h], clipped to [−1,1]. At alpha = 0.05, a half-width of 0.10 requires 738 independent families. This deliberately conservative bound shows why a small panel cannot provide assumption-free precision; it is not a proposal to collect 738 families. [Hoeffding, 1963](https://doi.org/10.1080/01621459.1963.10500830).

**Recommended decision:** define the initial external work as an estimation pilot unless the audited source inventory and prespecified uncertainty model justify a more precise comparison. Use a single primary comparator/endpoint for the new external family; supporting model or subgroup tests are exploratory unless a multiplicity plan is added in advance. The six historical physics slots and three historical enrichment slots remain unchanged and are not reused as extra external observations. Complete statistical coverage checks for the actual discrete outcome model before registration; the present analytic normal scenarios do not supply those checks.

## Functional evidence is a separate development analysis

Weng et al. (2024) provide KRAS abundance/binding measurements, inferred folding/binding free energies and associated analysis code, including evidence of mutational allosteric effects in four surface pockets. These data can inform a **KRAS development analysis**, not independent-family confirmation. [Weng et al., 2024](https://doi.org/10.1038/s41586-023-06954-0).

Before scoring, name the binding partner and state, exact assay/version, sequence map, input receiver, direct-interface exclusion, mutation aggregation, folding/abundance safeguards, measurement uncertainty and minimum coverage. Select a fixed residue-level summary of the eligible substitution effects; local mechanical stiffening does not represent a specific amino-acid substitution or establish its effect sign. No such assay threshold is invented here. A candidate declared experimentally inactive needs an assay-specific negligible-effect margin and uncertainty narrow enough to support it. Neither an unannotated pocket nor a nonsignificant mutation is a true inactive control. The MYH7 reference mismatch and MYC functional interpretation remain open; neither docking nor predicted conformations creates measured functional labels.
